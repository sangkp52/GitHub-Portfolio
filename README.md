🌐 Portfolio Website - GitHub Pages
📌 Giới thiệu

Đây là website portfolio cá nhân của mình, được xây dựng nhằm giới thiệu bản thân, kỹ năng và các dự án đã thực hiện.
Website được deploy bằng GitHub Pages để có thể truy cập nhanh chóng và miễn phí.

🔗 Live Demo: <br>

👉 https://sangkp52.github.io/GitHub-Portfolio/ <br>

## 🎯 Mục tiêu
- Xây dựng một trang web cá nhân chuyên nghiệp 
- Trình bày các dự án đã thực hiện 
- Thể hiện kỹ năng lập trình web (HTML, CSS, JavaScript)
- Tạo một nơi lưu trữ portfolio lâu dài 

## 🛠️ Công nghệ sử dụng
- HTML5 – xây dựng cấu trúc website 
- CSS3 – thiết kế giao diện, layout 
- JavaScript – thêm hiệu ứng và tương tác
- GitHub Pages – deploy website

## 🧠 Ý tưởng & thiết kế

Website được thiết kế theo phong cách tối giản (minimalist), tập trung vào nội dung chính và trải nghiệm người dùng.

## 🔹 Các phần chính
- About Me – Giới thiệu bản thân
- Resume – Tóm tắt học vấn & kỹ năng
- Projects – Các dự án đã thực hiện
- Certificate – Chứng chỉ
- Contact – Thông tin liên hệ <br>

🎨 Màu sắc chủ đạo: Đen (Dark theme) <br>
📱 Responsive: Tối ưu cho desktop <br>

##  ⚙️ Quá trình thực hiện
1. Khởi tạo project
Tạo repository trên GitHub
Clone về máy để phát triển
2. Xây dựng giao diện
Tạo cấu trúc HTML cho từng section
Thiết kế layout bằng CSS
Thêm nội dung cá nhân
3. Phát triển chức năng
Thêm hiệu ứng bằng JavaScript
Tối ưu responsive cho mobile
Kiểm tra UI/UX
4. Deploy website
Sử dụng GitHub Pages
Cấu hình branch (main hoặc gh-pages)
Kiểm tra lại sau khi deploy

## ⚠️ Khó khăn & cách giải quyết 
❌ Vấn đề: <br>
CSS bị lỗi khi deploy (không load file) <br>
Font chữ hiển thị chưa đẹp <br>

✅ Giải pháp: <br>
Kiểm tra lại đường dẫn CSS (dùng đường dẫn tương đối ./style.css) <br>
Sử dụng Google Fonts để cải thiện typography <br>
